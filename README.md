## 📌 Sobre o Projeto

Este projeto consiste em uma Landing Page responsiva e interativa desenvolvida do zero. O objetivo principal é centralizar meu portfólio de desenvolvimento, demonstrando conceitos práticos de **Front-End** (HTML, CSS e JS) e integração com conceitos de **Back-End** (Java e Spring Boot).

---

## ✨ Funcionalidades

- 🌓 **Modo Escuro / Claro (Dark/Light Mode):** Alternância de tema com persistência no navegador via `localStorage`.
- 📱 **Layout Totalmente Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- 🎯 **Filtro Dinâmico de Projetos:** Organização por categoria (Front-End, Back-End).
- 📜 **Scroll Reveal & Active Navigation:** Animações sutis ao rolar a página e indicador automático do menu ativo.
- ✉️ **Canais Rápidos de Contato:** Acesso direto a E-mail, GitHub e LinkedIn.

---

## 🛠️ Tecnologias Utilizadas

### **Front-End**
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Flexbox, CSS Grid, Variáveis CSS (`:root`) e Animações.
- **JavaScript (ES6+):** Manipulação da DOM, navegação e controle de tema.
- **Font Awesome:** Biblioteca de ícones vetoriais.

### **Back-End & Banco de Dados (Projetos Listados)**
- **Java:** Lógica de programação e POO.
- **Spring Boot:** Construção de APIs RESTful.
- **SQL / JPA:** Persistência de dados.
